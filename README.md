# 📊 German Credit Data Dashboard (Power BI)

This project visualizes key insights from a cleaned German credit dataset using **Microsoft Power BI**. It explores customer demographics, financial behavior, and credit patterns to help understand loan distribution and user profiles.

---

## 📁 Dataset Overview

The dataset includes anonymized information on **credit applicants**, with features such as:

- **CustomerID**: Unique identifier for each customer  
- **Age**: Age of the customer  
- **Sex**: Gender of the applicant  
- **Job**: Employment category (0 to 3)  
- **Housing**: Type of housing (own, rent, free)  
- **Saving accounts**: Savings account status  
- **Checking account**: Checking account status  
- **Credit amount**: Loan amount requested  
- **Duration**: Duration of the loan in months  
- **Purpose**: Reason for taking the loan

---

## 📌 Project Goals

- Understand customer credit behaviors and trends  
- Visualize demographic and financial characteristics  
- Create an **interactive and filterable dashboard**  
- Enable exploration by gender, purpose, job, and account status

---

## 📈 Power BI Visuals Used

The following visuals were implemented in the dashboard:

1. **Bar Chart** – Purpose vs Credit Amount  
   ➤ Highlights which loan purposes have the highest funding

2. **Column Chart** – Job vs Credit Amount  
   ➤ Shows credit distribution based on job category

3. **Pie Chart** – Housing Distribution  
   ➤ Displays customer housing type percentages

4. **Donut Chart** – Saving Accounts Distribution  
   ➤ Shows the distribution of savings account categories

5. **Treemap** – Purpose vs Credit Amount  
   ➤ Visualizes proportional loan amounts across purposes

6. **Matrix Table** – Sex vs Purpose  
   ➤ Compares loan purposes across gender

---

## 📄 Insights Explored

- Which loan **purposes** receive the most funding  
- Which **jobs** tend to borrow more credit  
- Gender-wise differences in **loan purposes**  
- How **housing and saving accounts** are distributed  
- Patterns between **loan duration** and **credit amount**

---

## 🚀 How to Use

1. Open the `.pbix` file in **Power BI Desktop**  
2. Explore the dashboard using filters (sex, job, purpose, etc.)  
3. Use slicers to segment and compare different customer profiles  
4. Interact with visuals to gain business or risk insights
